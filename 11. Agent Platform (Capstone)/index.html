📋 Recent jobs (org-scoped)

Three things to try.
1. Stop the auth service (Ctrl-C on :8001) and ask a question anyway. With VERIFY_MODE=local it still works — the agent service cached the public key. Switch to VERIFY_MODE=remote and the same action returns 503.
2. Log in as Alice, then Bob. Each sees only their own org's jobs — even though the gateway happily forwarded both requests.
3. Hit localhost:8002/jobs directly, bypassing the gateway. You still get a 401 — because the service authenticates itself. The gateway is a convenience layer, not the security boundary.
