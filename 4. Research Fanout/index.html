🧪 Concurrency Lab

No LLM needed — these run instantly and print real timings
The connection. Experiment 1 shows await in a for loop running 8× slower than gather. The research panel above is that exact lesson at the graph level: sequential mode awaits each branch in a loop, parallel mode fans out with Send(). Same trade, one level up.

And the catch: fan-in waits for all branches, so your total time is set by the slowest one. Three fast branches and one wedged branch = one wedged response. That's why production fan-out needs per-branch timeouts.
