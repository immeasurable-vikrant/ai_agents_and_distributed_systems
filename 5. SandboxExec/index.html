What to notice. The agent's retry loop lives in a subgraph — the parent trace shows 3 steps even when the coder internally wrote, ran, failed, and rewrote. That's the boundary doing its job: the parent doesn't need to know about attempts or stderr.

And try the "impossible" example. Ask it to fetch a bitcoin price. The sandbox has no network, so the code fails, the agent reads the error, rewrites — and fails again, because the problem is structural, not a bug. After 2 attempts it stops and says so honestly. A bounded retry loop that admits defeat is better than one that loops forever.
