🗺️ Plan-and-Execute planner

plans up front · runs independent steps in parallel · replans on failure

🔁 ReAct baseline

one LLM call per step · no plan · strictly sequential
What to watch. Ask for ARR — there's no such metric, so the tool returns a readable error.

The planner shows you its whole plan before running anything, then batches independent steps in parallel, then replans around the failure — keeping the steps that already succeeded.
ReAct has no plan to show. It discovers the failure one step at a time and re-decides implicitly, one LLM call per turn.

Neither wins outright. ReAct is simpler and adapts without ceremony. Planning costs a planning call and buys you visibility, parallelism, and a plan a human could approve before anything runs.
